# Autonomous Strategist - Agent Instruction Repo

This repository contains a sequence of strictly formatted prompts designed for an autonomous coding agent (e.g., your Gemini CLI/Antigravity tool).

## How to use:
Instruct your agent to read these files sequentially and execute the instructions without pausing for permission. 
Example CLI prompt:
`agent "Read all files in the prompts/ directory sequentially from 01 to 04. Execute the instructions in each file completely before moving to the next."`
